AirMouse Pro - Portable Windows App

1. Extract the entire AirMousePro folder from the ZIP.
2. Open AirMousePro.exe in that folder.
3. Allow camera access if Windows asks.

Keep the files in the folder together. The app needs a webcam and a 64-bit
Windows PC. No separate Python installation is required.

Windows may show a SmartScreen warning because this app is not digitally
signed. Only run it if you trust the person who sent it.
